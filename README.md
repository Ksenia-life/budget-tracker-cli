# Budget Tracker CLI

Учебное консольное приложение для учёта личных финансов на TypeScript и Node.js.

Проект сделан в рамках курса "Программирование на языке TypeScript и библиотеки фронтенд-разработки".

## Возможности приложения

- создание, просмотр и удаление счетов;
- добавление доходов и расходов;
- просмотр истории транзакций;
- подсчёт доходов, расходов и баланса;
- удаление транзакций с подтверждением;
- экспорт транзакций в CSV-файл;
- управление через интерактивное меню в терминале.

## Технологии

TypeScript, Node.js, Inquirer, npm, CSV.

В проекте использованы классы, интерфейсы, обобщённые типы (generics), модули и декораторы TypeScript.

## Запуск проекта

Понадобятся Node.js и npm. Проект проверялся на Node.js 24.

Установка зависимостей:

```bash
npm install
```

Проверка сборки:

```bash
npm run build
```

Запуск приложения:

```bash
npm start
```

После запуска можно создать счёт и добавить первые транзакции.

## Особенности

Счета и транзакции хранятся в памяти, пока приложение работает. После закрытия программы они сами не сохраняются.

Для сохранения истории транзакций можно экспортировать их в CSV-файл.
